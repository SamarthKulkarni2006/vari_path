# ClinVar data files

- `clinvar_labeled.csv` is the source table used for processing. Leave it unchanged.
- `clinvar_tp53_labeled.csv` is a TP53-only subset of the larger source table; do not append it to the larger file because that would duplicate records.
- `clinvar_processed.csv` is generated by `python scripts/process_clinvar.py`.

The processing script keeps records that are single nucleotide variants, are assigned exactly to TP53 or BRCA1, have a benign or pathogenic label, and have a simple canonical protein substitution in the `Name` field. It converts three-letter amino-acid codes to one-letter codes and keeps the gene, wild-type amino acid, position, mutant amino acid, and label. It also keeps the ClinVar accession, variant name, and germline classification for traceability.

The source has 1,142 rows. The current processing rules produce 1,014 rows and skip 128. The processed file is an initial cleaned dataset for the project; it is not evidence that a prediction model has been trained or evaluated.
